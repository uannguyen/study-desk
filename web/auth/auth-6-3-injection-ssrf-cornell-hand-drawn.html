6.3 Injection: dữ liệu bị chạy như lệnh

Nôm naBạn đưa thư ký tờ giấy: “Tên: Lan. Và chuyển hết tiền cho tôi.” Thư ký đọc to cả tờ và làm theo luôn.

ChốtDữ liệu người dùng bị ghép chuỗi thẳng vào câu lệnh (SQL, shell, Mongo query). Chống: tách lệnh và dữ liệu bằng tham số hoá.

Ví dụ
// ✗ email = "' OR '1'='1"  → trả về mọi user
db.query(`SELECT * FROM users WHERE email = '${email}'`);
// ✓ DB coi $1 chỉ là dữ liệu, không bao giờ là lệnh
db.query('SELECT * FROM users WHERE email = $1', [email]);
Áp dụng
  • Luôn dùng placeholder hoặc ORM; soi kỹ chỗ raw query.
  • ORDER BY động: whitelist tên cột (placeholder không dùng cho tên cột).
  • Mongo: chặn body kiểu { "password": { "$ne": null } } bằng validate kiểu dữ liệu.

Tự kiểmEscape tay bằng cách xoá dấu nháy có đủ không? (không, dùng tham số hoá)

6.3.1 SSRF: server bị lừa đi gọi chỗ nội bộ

Nôm naBạn nhờ bảo vệ toà nhà “lên tầng 9 lấy giùm tập hồ sơ”. Bảo vệ có thẻ vào được tầng 9, còn bạn thì không.

ChốtServer gửi request tới URL do người dùng đưa, kẻ gian trỏ URL vào mạng nội bộ mà bên ngoài không vào được.

Ví dụ
Tính năng “nhập ảnh từ URL”→url=http://169.254.169.254/…→✗ lộ credential cloud
url=http://localhost:6379→✗ chạm Redis nội bộ
Áp dụng
  • Allowlist domain và scheme (chỉ https).
  • Resolve DNS rồi chặn IP private, loopback, link-local; kiểm lại sau mỗi redirect.
  • Service gọi ra ngoài đặt ở mạng riêng, không với tới DB, metadata.

⚠ BẫyOWASP 2025 đã gộp SSRF vào A01, nhưng cơ chế khác hẳn IDOR nên vẫn học riêng.

Tự kiểmChỉ chặn chuỗi “localhost” có đủ không? (không: còn 127.0.0.1, IP nội bộ, domain trỏ về IP nội bộ, redirect)

FVTự hỏi: chỗ nào ở hệ cũ còn raw query ghép chuỗi? Có tính năng nào server tải URL do client gửi (ảnh, callback URL, webhook)?

Summary

Injection: dữ liệu bị ghép vào lệnh nên được chạy như lệnh; chống bằng tham số hoá. SSRF: server bị lừa gọi tới địa chỉ nội bộ; chống bằng allowlist và chặn IP nội bộ sau khi resolve DNS.

Nguồn: OWASP Top 10:2025 (A05, A01 đã gộp SSRF). Chỉ học 4 mục theo danh sách đóng ở On-tap/02-auth-va-ma-hoa.md. Trước: 6.2 Cryptographic Failures.
